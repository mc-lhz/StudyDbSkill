# norms —— 答题规范枚举（唯一真源）

> 8 条。错题记录的 `norm` 字段只能取这些值，校验失败退出码 `4`。
> 与 `causes.md`（错因）、`kinds.md`（知识点类型）、`taxonomy.md`（章节）并列，是四份真源之一。

**这四处的知识点你会，但表达方式让你丢分。**
不建这份真源，它们会被误归进 `概念混淆`，补救方向整个跑偏——
去背概念，其实概念早就会了。

## 枚举表

| norm | 含义 | 正例 → 反例 |
|---|---|---|
| `因果完整` | 写全 A→B→C，不跳中间环节 | 「血糖升高→下丘脑→垂体→胰岛A细胞」而非「血糖升高→胰岛A细胞」 |
| `术语规范` | 用课本原词 | 「促进」不写「加快」；「抑制」不写「阻止」；「重吸收」不写「泌尿」 |
| `名称写全` | 全称不写简称 | 「神经—体液—免疫调节**网络**」而非「神经—体液—免疫调节」 |
| `限定准确` | 一定/主要/根本/只能 不漏不错 | 「药物X**只能**阻断神经元之间的传递」 |
| `要点答全` | 问「来源/途径」要列全 | 「血糖来源：肝糖原分解、非糖物质转化、食物中糖类消化吸收」 |
| `量变答趋势` | 写「增加幅度」不只写「增加」 | 见下方专条 |
| `指向明确` | 答具体部位/物质，不写大类 | 问「Ⅱ过程」答「重吸收」而非「泌尿」 |
| `单位齐全` | 数值必须带单位 | 「pH 下降约 0.1」而非「pH 下降」 |

## `量变答趋势` 值得单独说

负反馈的量变是本册最高频的**表述陷阱**，单独立一条。

> **抑制作用减少 ≠ 抑制作用**
>
> 例：血液中甲状腺激素含量下降 → 对下丘脑的**抑制作用减弱**
> → 下丘脑分泌促甲状腺激素释放激素**增加**
>
> 写成「抑制作用减少 → TRH 减少」或「抑制 → TRH 减少」都错，
> 错在把「抑制的减弱」当成了「抑制」。

三个字要分清：**减弱 / 减少 / 取消**。
- 减弱 = 程度下降，仍存在 → 下游**增加**
- 减少 = 量变少，仍存在 → 相对量**减少**
- 取消 = 不存在 → 下游**恢复到基础水平**

来源：2026-10-16 月考 19(4)，红笔原话「最好写『增加幅度减少』」。

## 与 `causes` 的分工

| | `cause` | `norm` |
|---|---|---|
| 回答的问题 | 我为什么不会 | 我为什么会**表达错** |
| 补救方向 | 补知识 / 建对照卡 | 练规范 / 背标准表述 |

**一条错题可以同时有 `cause` 和 `norm`**：概念确实会了但没按规范答，
`cause` 记 `会但粗心`，`norm` 记 `限定准确`。

⚠️ **不要把所有失分都归到 `norm`**。`norm` 只在**知识点确实掌握了**时使用——
判断依据是红笔批注里有没有给出规范性的批改（「最好写…」「漏了…字」）。
红笔只是圈出答案不算 `norm`，那是 `概念混淆`。
