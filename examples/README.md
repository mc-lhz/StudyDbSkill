# examples —— 虚构夹具

**本目录下所有内容均为从零编造，不含任何真实错题、真实姓名、真实学校。**

用途有三个：

1. `TestCases/` 的单元测试夹具（不消耗真实错题）
2. `SKILL.md` / `README.md` 的格式示范
3. 打包发布时的示例（若将来开源）

## ⚠️ 纪律

新增夹具时**必须从零编造题目内容**。

**不许**拿真实错题改个名当示例——那是脱敏工作流最常见的破口：
改掉的只是字面表述，题目结构、设问角度、乃至学生特有的错误模式都还在，
一眼就能认出来是「某某的卷子」。

正确做法是**编一道结构相似但内容完全不同的题**：
保留「这道题考什么知识点」，换掉所有具体情境、数据、设问。

## 目录

```
data/subjects/生物/
├── exams/BIO-20261013-01.md      考试档案（虚构）
├── errors/
│   ├── BIO-20261013-001.md       已确认的错题（verified: true）
│   └── BIO-20261013-002.md       AI 草稿未确认（verified: false）
├── points/KP-20261013-01.md      对照类知识点（虚构）
├── assets/BIO-20261013-001-01.png 程序生成的占位图
└── indexes/                       派生，工具生成，此处留空
```

这组夹具刻意覆盖了几种边界情况：

| 文件 | 演示什么 |
|---|---|
| `001` | `verified: true` + 有 `point_ref` + 有图片引用 + `会但粗心` 不允许一次过的规则 |
| `002` | `verified: false`（AI 草稿）+ **`point_ref` 为空**（错题指向知识点是可选的） |
| `KP-01` | `kind: 对照`（生物杀手锏类型），`易混对象` 必填 |
