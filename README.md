# 错题仓 · BioErrorVault

> 本 md 仅供人阅读。AI 助手请直接读 `SKILL.md`。

生物错题 + 零碎知识点的存储与复习工作流。两个仓库，各司其职：

| 仓库 | 位置 | 干什么 |
|---|---|---|
| **工具仓** | `~/.config/opencode/skills/bio-error-vault/` | 命令、三份枚举真源、虚构夹具。**可分发、可开源** |
| **数据仓** | `~/Documents/bio-error-data/` | **你的真实错题与知识点**。本地 git，**不上传** |

数据仓永远是私密的：里面有学校名、手写姓名、考号、卷子照片。
**不要给数据仓加远程仓库**——推到公开地方，即使后来删掉文件，git 历史里也找得回来。

## 现在能做到什么

对 AI 说：

- 「今天生物做了第三章，选择题错两道，都是有氧呼吸，一道忘了柠檬酸循环在哪，一道算错了丙酮酸数量」
- 「整理一下主动运输和被动运输的区别」
- 「我拍的这张卷子，帮我把错题挑出来」

AI 会把它们转成结构化记录存进数据仓，**并等你确认后才计入统计**。

## 现在还做不到什么

还在 Phase 0（地基）。**复习队列、薄弱点统计都还没做。**

| | 状态 |
|---|---|

这一步过不了，后面全是空中楼阁。

## 为什么要这么设计

一句话：**错题集是症状，知识点集是病灶。**

「第几章错得多」是症状级信息。「这条知识点被 8 道错题引用过」才是病灶级信息。
所以错题挂知识点（`point_ref`），统计落在知识点上。

知识点从真实错题里长出来，不是凭想象攒条目——后者必然产出大量
「看着对但用不上的卡片」，最后变成第二本翻不动的笔记本。

细节见 `AGENTS.md`。

## ⚠️ 一条不可跳过的规矩

**AI 生成的错因判断和标准答案，一律先标记为「未确认」，不计入统计。**

因为生物术语错一个字（「线粒体基质」写成「线粒体基质胶」）、
过程阶段记错，照着背就是**学错东西，比不学更糟**。

所以每次录入后 AI 都会请你复核一遍。这道闸门不能图省事跳过——
闸门一松，所有统计立刻失效。

## 最重要的一句

这套系统的价值在于**复习时真的会打开它**。

哪天你觉得维护它比直接翻卷子还累，一定是 schema 太重或录入太慢——
**砍工具，不砍复习。** 沉没成本是最大的陷阱。
